# 지원 범위와 제한

- 텍스트·구문 검색입니다. 컴파일, 의미 바인딩, 실제 타입·오버로드·참조 판별을 하지 않습니다.
- 파일 목록을 먼저 만들고 선언은 필요한 파일만 읽습니다. 파일명 우선 결과의 범위 경고를 확인하세요. 미발견·0건은 선언 부재 증거가 아닙니다.
- csproj의 Compile Include/Remove·imports·조건·상위 빌드 설정을 평가하지 않습니다. 프로젝트에 포함되지 않은 파일도 후보가 될 수 있습니다.
- 직접 기재된 DefineConstants만 구문 파서에 전달합니다. 실제 빌드 구성의 활성 분기 일치는 확인 필요입니다.
- 동명 메서드·부분 클래스·인터페이스·DI·가상 호출·동적 문자열은 원문으로 대조해야 합니다.
- UI 문구와 Designer 이벤트 연결은 정적 후보입니다. 런타임 연결·문구 변경·리소스 변형은 누락될 수 있습니다.
- DB 명령 설정은 실행 증거가 아닙니다. helper의 명령은 해당 helper를 별도로 검색합니다. 미사용 설정도 후보로 반환할 수 있습니다.
- Adapter 이름·행 상태 매핑은 후보입니다. 같은 이름의 타입, 상속, FillBy·SelectCommand, 삭제 행만 전달한 Update는 원문 확인이 필요합니다.
- Ready는 파일 목록과 검색 준비 상태이며 구문 진단은 읽은 파일에 한정됩니다. CompilationErrors는 미평가입니다.
- 파일 감시 알림은 비동기이며 주기적 대조로 보완합니다. 즉시 대조가 필요하면 reload_solution을 사용합니다.
- SQL은 로컬 파일만 읽습니다. 직접 참조·변경 후보는 SQL 실행 증거가 아닙니다. 동적 SQL·별칭·간접 참조·운영 DB 일치는 확인 필요입니다.
- 읽을 수 없는 경로는 검색에서 누락될 수 있습니다. 원본 파일 수정·DB 연결·SQL 실행은 하지 않습니다.
- HTTP 공유 서버는 모든 클라이언트의 호출을 한 번에 하나씩 처리합니다. 다른 클라이언트의 긴 호출이 끝날 때까지 기다릴 수 있습니다.
- HTTP 공유 서버에는 인증이 없습니다. 루프백 주소만 허용하므로 다른 PC에서는 접속할 수 없지만 같은 PC의 다른 프로세스는 접속할 수 있습니다.
- HTTP 공유 서버에서 분석 대상을 바꾸려면 서버 설정을 바꾸고 다시 시작해야 합니다. `load_solution`·`select_database_source`는 기본 차단입니다.
- 제거된 도구·입력·응답 변경은 tools.md를 참고하세요. 기존 프롬프트·클라이언트 갱신이 필요합니다.
